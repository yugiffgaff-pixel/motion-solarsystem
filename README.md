# 太阳系

一个可拖动时间的三维太阳系。轨道距离用天文单位，倾角和偏心率都保留。时间从公元前 10000 年 1 月 1 日到公元 10000 年 1 月 1 日。

## 运行

```bash
npm install
npm run check
npm run dev
```

构建静态页：

```bash
npm run build
npm run preview
```

## 操作

- 拖底部的时间条跨过这两万年。它很长，一个像素对应很多年，所以旁边有 ±180 天的细调、±1 天、±10 年和日期输入。
- 播放速度从每天半秒到大约一百年每秒。
- 左侧点名称，或在画面里点星体，相机会靠过去并跟着走。
- 「全貌」看外层轨道，「内行星」看水星到火星。
- 显示倍数只放大星球半径。1 倍是真实大小。带卫星的星体放到卫星轨道允许的上限后就不再变大。

## 位置

- 八大行星：NASA JPL 开普勒近似（3000 BC–3000 AD 的表 2a，木星到海王星加表 2b）。地球由地月质心减去月球质量比得到。
- 月球、木卫一至四、土卫六：JPL 行星卫星平根数，历元 2000-01-01.5 TDB。伽利略卫星和土卫六从拉普拉斯平面转到 J2000 黄道。
- 谷神星、冥王星、妊神星、鸟神星、阋神星：JPL 小行星数据库的密切轨道，两体传播。
- 日期是向两端外推的公历，没有加 ΔT。自转用来看表面，没有做岁差，也没有把本初子午线对到星历上。
- 小行星带是示意粒子。

JPL 给行星公式公布的精度只覆盖公元前 3000 年到公元 3000 年。时间条在这段外面仍用同一公式，轨道大小还在，相位会漂。页面上会标出来。

## 纹理

太阳、水星、金星云层、地球、地球云、月球、火星、木星、土星、土星环、天王星、海王星来自 [Solar System Scope](https://www.solarsystemscope.com/textures/)，CC BY 4.0。木卫一至四和土卫六来自 NASA 3D Resources。谷神星是 Dawn 全球地形设色图（NASA / JPL-Caltech / UCLA / MPS / DLR / IDA），颜色表示高度，原图带经纬网。冥王星是新视野号彩色镶嵌图（NASA / JHUAPL / SwRI），黑色是当时没拍到的区域。妊神星、鸟神星、阋神星没有全球影像，只按公开色调铺了一层。
